# Drop KPT — Timeline-Only Recap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the `### KPT` layer from the recap block so an auto- or manual-recap writes only a `### Timeline`, and session headings carry a time range with no topic.

**Architecture:** The recap block is produced by `recap/autorecap/block.py:upsert_session_block`, fed either by the Stop hook (`recap/autorecap/__main__.py`, which calls headless `claude -p` with one of two prompt templates) or by the `garden-recap` skill (`recap/manual_recap/__main__.py`). KPT threading runs through all three plus both prompts. Each task removes it from one layer, innermost first, so every task leaves the suite green.

**Tech Stack:** Python 3 (stdlib only), pytest. Markdown prompt templates. Repo pre-commit hooks: markdownlint, `check-skill-refs`, SKILL.md frontmatter, version-match across `package.json` / `.claude-plugin/plugin.json` / `.claude-plugin/marketplace.json`.

**Spec:** `docs/specs/2026-09-08-drop-kpt-design.md`

## Global Constraints

- Target release **v0.22.0**. The version-match pre-commit hook requires `package.json`, `.claude-plugin/plugin.json`, and `.claude-plugin/marketplace.json` to agree — bump all three in Task 6.
- `upsert_session_block` must stay **byte-idempotent**: re-applying identical inputs to an already-written block returns the text unchanged.
- The legacy `kg-recap-sid:{sid8}-{HHMM}` block form must keep NOT matching a bare `{sid8}` marker (the `(?![-\w])` guard in `_open_re` / `_close_re`).
- Timeline append-with-dedup behaviour is unchanged by this work.
- No backward-compat shims. Removed parameters are deleted, not defaulted. A caller passing `kpt_section=` or `topic=` must raise `TypeError`.
- Run the full suite with `python3 -m pytest tests/ -q` from the repo root.
- Branch: `feat/drop-kpt` (already created, spec already committed).

```python
def _render_header(start: str, end: str) -> str:
    return f"## Session {start}〜{end}"


def _new_block(sid8, start, end, timeline_bullets) -> str:
    parts = [
        f"<!-- kg-recap-sid:{sid8} -->",
        _render_header(start, end),
        "",
        "### Timeline",
        *timeline_bullets,
        f"<!-- /kg-recap-sid:{sid8} -->",
    ]
    return "\n".join(parts) + "\n"


def upsert_session_block(note_text: str, sid8: str, *, start_hhmm: str, end_hhmm: str,
                         timeline_bullets: list[str], insert_before: str = "") -> str:
    om = _open_re(sid8).search(note_text)
    cm = _close_re(sid8).search(note_text)
    if om and cm and cm.start() > om.start():
        block = note_text[om.start():cm.end()]
        # refresh end; start = earliest of the existing header and the incoming
        # window (a manual full-session recap can begin earlier than an auto
        # block that started mid-session; monotonic auto increments are later,
        # so the existing start is preserved for them).
        hm = _HEADER_RE.search(block)
        start = min(hm.group(1), start_hhmm) if hm else start_hhmm
        new_header = _render_header(start, end_hhmm)
        block = _HEADER_RE.sub(lambda _m: new_header, block, count=1) if hm else block
        # replace timeline wholesale — caller owns the full list each Stop
        tm = _TIMELINE_RE.search(block)
        if tm:
            block = block[:tm.start(2)] + "\n".join(timeline_bullets) + block[tm.end(2):]
        # normalize section spacing so re-applying identical inputs is a byte-level no-op
        # (matches _new_block: one blank line before each ### subheading, none before the close marker)
        block = re.sub(r"\n+(### )", r"\n\n\1", block)
        block = re.sub(r"\n+(<!--\s*/kg-recap-sid:)", r"\n\1", block)
        return note_text[:om.start()] + block + note_text[cm.end():]

    # block absent → build and insert
    new = _new_block(sid8, start_hhmm, end_hhmm, timeline_bullets)
    anchor = insert_before.strip()
    m = re.search(r"\n" + re.escape(anchor), note_text) if anchor else None
    if m:
        return note_text[:m.start()] + "\n" + new + note_text[m.start():]
    sep = "" if note_text.endswith("\n") or not note_text else "\n"
    return note_text + sep + new
```

- [ ] **Step 3: Write the strip script**

```python
#!/usr/bin/env python3
"""Strip `### KPT` / `## KPT` sections from daily notes. Prints a diff; --apply writes."""
import difflib
import pathlib
import re
import sys

# A KPT section runs from its heading to the next heading of the same or higher
# level, the block close marker, or EOF.
KPT_RE = re.compile(
    r"^#{2,3} KPT[ \t]*\n.*?(?=^#{1,3} |^<!-- /kg-recap-sid:|\Z)",
    re.DOTALL | re.MULTILINE,
)

def strip(text: str) -> str:
    out = KPT_RE.sub("", text)
    out = re.sub(r"\n{3,}", "\n\n", out)                      # collapse the hole
    out = re.sub(r"\n+(<!--\s*/kg-recap-sid:)", r"\n\1", out)  # match block spacing
    return out

def main(argv):
    apply = "--apply" in argv
    root = pathlib.Path("vault/04_DailyNotes")
    changed = 0
    for f in sorted(root.glob("*.md")):
        old = f.read_text(encoding="utf-8")
        new = strip(old)
        if new == old:
            continue
        changed += 1
        if apply:
            f.write_text(new, encoding="utf-8")
        else:
            sys.stdout.writelines(difflib.unified_diff(
                old.splitlines(keepends=True), new.splitlines(keepends=True),
                fromfile=str(f), tofile=f"{f} (new)",
            ))
    print(f"\n{changed} file(s) {'changed' if apply else 'would change'}", file=sys.stderr)
    return 0

if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1:]))
```
